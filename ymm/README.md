# Sa_aohue for YMM4 — 0.4.0

線に沿って彩度・輝度・色相を調整するYMM4用エフェクト。今回の更新はYMM4のみで、AE側は変更していません。

色の回り込み0%では、彩度0%は無変化、100%はマスク最大部でクロマ2倍、-100%は無彩色化です。
線マスクは効果が強い部分が白、線マスク反転はその逆です。
RGB Encodingと自然な鮮やかさは削除しました。入力はsRGB前提です。HDR画素の色調整、非sRGB/線形ワークスペースは保証対象外です。

## 数値実装：色の回り込み

「色の回り込み」は、数値プレビューで使った `OKLab の近傍クロマ差` をGPU上へ移したものです。入力をOKLabへ変換し、`a`/`b` とアルファ重みを32bit浮動小数でGaussian平均します。線マスクの近傍で、平均クロマとの差を加えるため、白に近い領域へ周囲の青や赤を回り込ませられます。

- **正値**：近傍の色を線の周囲へ寄せます（色の回り込み）。
- **負値**：近傍色から離す方向へ動かし、境界の色差を強調します。
- **0%**：新しい色場を使わず、従来の処理と同じです。
- 強さは点ノイズ除去後の線マスクを使い、既存の「適用する側」にも従います。
- `変化範囲` は色場のGaussian半径にも使われます。色の回り込みだけを有効にした場合、`彩度`を0%にしても回り込みは動作します。

色場は1枚の入力フレームから作るため、物体の意味や3Dの凹みを推定する処理ではありません。透明境界ではアルファ重みで近傍色を正規化します。大きい半径では追加のGPU Gaussianパスが必要になるため、1080pではまず16–32px程度から確認してください。

## 4つの追加設定

- **強弱の反映**：0%では検出した線を一律に扱い、100%では正規化DoG応答 / 0.25（上限1）に比例して彩度・輝度・色相の変化を弱めます。フレーム内最大値による正規化は行いません。
- **点ノイズ除去**：検出マスクの8近傍連結成分について、幅・高さがともに指定px以下の孤立部分を除去します。3なら最大3×3pxです。原画の点の大きさではなく、検出サイズ・しきい値を通した後の大きさです。7×7の局所探索で判定し、窓境界まで続く成分は保持。長い細線・斜線は残りますが、意図した短い点も除去対象になります。0では追加パスをバイパスします。
- **安定性**：しきい値から上の幅 0.08 × 設定/100 を滑らかな立ち上がりにします。弱い線ほど薄くなり、しきい値付近の微小な明暗変化による点滅を軽減します。過去フレーム保持・時間平均・動き追跡は行わず、シーク・逆再生・再評価の順序に依存しません。大きな動きや点ノイズ除去の連結状態変化によるちらつきは防げません。
- **適用する側**：検出点の広いGaussianで得たOKLab Lを、線の重み付きで変化範囲に広げ、各画素のOKLab Lと比較します。明るい側／暗い側は相補的で、境界±0.005 Lを滑らかに切り替えます。最終マスクに適用するため、ぼかしが反対側へ広がるのを抑えます。画面の左右・物体の内外ではありません。複数の線が重なる場所では参照明度が混ざります。

追加項目は初期値で無効（側は両側）。v0.2の保存名・既存enum値を保ちます。使い始めの目安は強弱の反映100%、点ノイズ除去2–3px、安定性50%です。線マスク出力で適用範囲を確認してください。

## 検出・ぼかし

- sRGBをデコードし、従来同様OKLab Lを線検出に使用します。
- 横・縦の分離Gaussian（σと1.6σ、半径ceil(3σ)）の差分を正側L1ノルムで正規化します。
- 横パスでは小/大Gaussianの輝度×アルファとアルファ重みを4チャンネルに保持し、縦パス後に割ります。中間は32bit floatです。
- 画像外を明示的に除外し、透明・半透明部分を重み付き正規化します。
- 内部しきい値は (表示値 / 255) × 0.08。先行仕様書の0.04は正規化後のノイズ基準を満たさなかったため修正しました。
- 変化範囲はDirect2D GaussianBlurの標準偏差へ直接渡します（Quality / Soft）。0では接続を切り替え、ぼかしを完全に省略します。
- ぼかしマスクもRGB/alphaで正規化します。コントラスト1ではpowを省略します。
- 色域内の目標色には二分探索を行いません。色域外のみ12回探索します。

## 互換性

既存のAmount/Radius/Contrast/Brightness/HueShift/LineThreshold/OutputMode/InvertLinesという保存名と出力enum値は維持しました。
削除したVibrance/RgbEncodingは実装から除去しています。旧プロジェクトの未知プロパティ取り扱いはYMM4実機で要確認です。

**v0.1と見た目は一致しません。** 検出器、変化範囲の尺度、マスク出力の極性が変わります。検出サイズは新規初期値1.0です。更新前にプロジェクトと旧DLLをバックアップしてください。

## ビルド・インストール

GitHub Actionsの「YMM4 build」は公式YMM4 LiteのDLLを参照し、Windows SDKのfxcで5つのシェーダーをコンパイルします。
成功した実行のArtifactsからSaAohueYmmをダウンロードできます。

.NET 10 SDK、YMM4のDLLフォルダ、Windows SDKのfxc.exeとd2d1effecthelpers.hlsliを指定します。

```powershell
dotnet build ymm/SaAohueYmm.csproj -c Release "-p:YMM4DirPath=C:\\path\\to\\YMM4\\" "-p:FxcPath=C:\\path\\to\\fxc.exe" "-p:D2DIncludePath=C:\\path\\to\\sdk\\um"
./ymm/check-shaders.ps1 -FxcPath C:\\path\\to\\fxc.exe
```

生成されたSaAohueYmm.dllをYMM4のuser/plugin/SaAohueYmm/へコピーし、YMM4を再起動します。

- python tests/test_ymm_v02.py: 独立2次元畳み込みとfloat32分離処理の比較、透明境界、ノイズ、極性、UI/処理契約。
- dotnet run --project ymm/tests/KernelTests.csproj -c Release: 本番C#カーネルの合計・L1ノルム・範囲。
- g++ -std=c++17 -O2 tests/check_ymm_line_controls.cpp -o /tmp/ymm-controls && /tmp/ymm-controls: 本番と共通のHLSL関数を実行し、216,600件の連結判定を独立した画像全体の探索と照合。強弱単調性・しきい値揺れ・片側の相補性も検証。
- check-shaders.ps1: 5シェーダーの座標入力と定数バッファ配置。
- YMM4の実画面での描画、旧プロジェクト読込、保存・再読込、アニメーション、GPU別の動作確認は別途必要です。参照テストはGPUの実行結果を保証しません。
